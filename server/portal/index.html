📲 УСТАНОВКА НА ТЕЛЕФОН

iPhone (Safari): «Поделиться» → «На экран Домой». Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран». Откроется на весь экран, как обычное приложение, с иконкой ZALET HOME.

Системные пуш-уведомления браузеры разрешают только по HTTPS, а панель работает по http внутри дома, поэтому уведомления приходят в Telegram (Журналы → настройки событий).
