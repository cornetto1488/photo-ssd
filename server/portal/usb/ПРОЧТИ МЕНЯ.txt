ZALET HOME — флешка для входа домой
=====================================

КАК ПОЛЬЗОВАТЬСЯ
  1. Вставьте флешку в компьютер с Windows и откройте её.
  2. Дважды нажмите «ZALET HOME» и разрешите запуск от администратора.
  3. Флешка сама:
       • поставит Tailscale, если его нет (установщик лежит на флешке, интернет для этого не нужен);
       • подключит компьютер к домашней сети;
       • откроет панель дома в браузере: http://100.113.69.110
  Если вы дома в Wi-Fi или Tailscale уже подключён, панель откроется сразу.

  «Отключиться» — вывести компьютер из домашней сети. Там же можно удалить
  Tailscale с чужого компьютера, чтобы не оставлять следов.

  Сам по себе при вставке флешки ничего не запускается: Windows запрещает
  автозапуск с флешек (защита от вирусов). Поэтому нужен один двойной клик.

LINUX (Ubuntu, Astra, Mint, Debian, Fedora…)
  1. Вставьте флешку и откройте её в файловом менеджере.
  2. Правый клик по пустому месту → «Открыть в терминале» и введите:
         bash zalet-linux.sh
     (или двойной клик по zalet-linux.sh → «Запустить», если менеджер предлагает)
  3. Введите пароль администратора компьютера (sudo) — дальше всё само:
     Tailscale ставится с флешки (без интернета, для обычных ПК x86-64),
     подключается к дому и открывается панель.
  Отключиться:  bash zalet-linux.sh stop   (там же можно удалить Tailscale)


КЛЮЧ ПОДКЛЮЧЕНИЯ (один раз)
  Ключ лежит в скрытой папке .zalet, в файле key.txt — одна строка.

  Постоянный ключ, который не истекает (рекомендуется):
    1. https://login.tailscale.com/admin/acls — в начало политики добавьте:
         "tagOwners": { "tag:usb": ["autogroup:admin"] },
       и сохраните.
    2. https://login.tailscale.com/admin/settings/oauth — Generate OAuth client:
         Scopes: Keys → Auth Keys → Write, тег tag:usb.
    3. Скопируйте Client secret (начинается с tskey-client-…) в .zalet\key.txt.
    Компьютеры с флешки появятся в Tailscale с меткой usb и сами не отвалятся.

  Простой вариант: https://login.tailscale.com/admin/settings/keys →
    Generate auth key → Reusable (галочка). Действует до 90 дней —
    это предел Tailscale; потом вставьте новый ключ в key.txt.

  Важно: с этим ключом любой, у кого окажется флешка, попадёт в домашнюю
  сеть. Если флешка потеряется, удалите ключ (или OAuth client) в Tailscale —
  он сразу перестанет работать.


ЧТО НА ФЛЕШКЕ
  ZALET HOME.cmd        — подключиться и открыть панель
  Отключиться.cmd       — отключиться (и при желании удалить Tailscale)
  zalet-linux.sh        — то же для Linux (bash zalet-linux.sh / ... stop)
  .zalet\start.ps1      — сценарий подключения
  .zalet\stop.ps1       — сценарий отключения
  .zalet\key.txt        — ключ подключения
  .zalet\tailscale-setup-amd64.msi — официальный установщик Tailscale для Windows
  .zalet\tailscale_amd64.tgz       — официальный Tailscale для Linux
